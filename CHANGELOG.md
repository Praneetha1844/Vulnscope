## [0.1.0]

### Added

- Parsers for SARIF 2.1.0, OSV-Scanner, pip-audit and npm audit reports.
- Duplicate merging, line-independent fingerprints and safe code excerpts.
- Python import-graph reachability and transparent scoring.
- Pluggable model providers with validated structured suggestions.
- Patch guardrails, a review state machine and an SQLite store.
- Proposed suppression rules learned from reviewer decisions.
- Markdown and SARIF reports, and a command line interface.
